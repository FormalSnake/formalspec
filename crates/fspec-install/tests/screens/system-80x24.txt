  Fedora Atomic
  Fedora as an image: updates land whole and the previous one stays in the
  boot menu.

  fixed            New versions arrive in scheduled releases you upgrade to.
  systemd          Services start with systemd, as on most distros.
  signed kernel    Boots with Secure Boot on, and anti-cheat that checks
                   kernel signatures trusts it.
  image            The system is a bootc image: updates apply whole, and the
                   previous image stays bootable.
  based on Fedora  Uses Fedora's packages, with its own changes on top.
